
# TSA Complaints Analysis

## 🎯 Overview
This project analyzes traveler complaints filed with the Transportation Security Administration (TSA) across various U.S. airports. The dataset includes monthly counts of complaints categorized by airport, category, and subcategory, providing insights into traveler experiences and recurring issues over time.

## 🧠 Objectives
- Analyze complaint trends by airport, category, and subcategory.
- Identify airports with the highest and lowest complaint rates.
- Examine seasonal variations in complaint frequencies.
- Provide actionable insights to improve TSA operations and traveler satisfaction.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib, Seaborn
- Jupyter Notebook

## 📁 Dataset
- **Source:** [TSA Complaints Dataset](https://github.com/nmonareng/TSA-Complaints)
- **Features:** Airport code, complaint category, subcategory, year and month, complaint count.

## 🔍 Key Findings
- **Top Airports by Complaints:** Identified airports with the highest number of complaints per 100,000 passengers.
- **Common Complaint Categories:** Highlighted prevalent issues such as "Mishandling of Passenger Property" and "Security Screening."
- **Seasonal Trends:** Observed peak complaint periods during holiday travel seasons.

## 📈 Visualizations
The project includes various visualizations to illustrate the findings:
- **Heatmaps:** Correlation matrices showing relationships between variables.
- **Bar Charts:** Displaying complaint counts by category and airport.
- **Time Series:** Tracking complaint trends over time.
