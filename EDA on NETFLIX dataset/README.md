
# Exploratory Data Analysis on Netflix Dataset

## 🎯 Overview
This project explores Netflix's content library using exploratory data analysis (EDA). The goal is to uncover patterns related to content type, genre, release year, and more to better understand Netflix’s global media strategy.

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 📁 Dataset
- **Source:** [Netflix Movies and TV Shows dataset on Kaggle](https://www.kaggle.com/shivamb/netflix-shows)
- **Features Include:**
  - `type`, `title`, `director`, `cast`, `country`, `release_year`, `rating`, `duration`, `listed_in`

## 🔍 Objectives
- Analyze trends in content types (movies vs TV shows)
- Visualize country-wise content production
- Examine genre distribution and time trends
- Investigate content ratings and durations

## 📈 Key Insights
- U.S. dominates content availability
- Surge in new content after 2016
- Most shows are rated for mature audiences

## 📉 Future Enhancements
- Time-series analysis on release patterns
- NLP on descriptions to cluster content by theme
- Dashboard using Plotly or Streamlit
