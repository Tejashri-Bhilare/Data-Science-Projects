
# AI & ML Salaries Analysis

## 🧠 Overview
This project explores salary trends in Artificial Intelligence and Machine Learning roles, examining variations based on job title, experience, company size, and region.

## 📊 Objectives
- Analyze compensation across roles (e.g., Data Scientist, ML Engineer)
- Compare salaries by geography and company size
- Identify insights from experience levels and job functions

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## 📁 Dataset
- Source: AI/ML Salary datasets (e.g., Kaggle)
- Columns include: `job_title`, `experience_level`, `company_size`, `salary_in_usd`, `location`, etc.

## 📈 Key Findings
- Salary increases with experience level and company size
- Remote roles increasingly competitive globally
- The U.S. dominates high-salary positions

- Add regression models for salary prediction
- Explore interactive dashboards with Streamlit or Plotly
